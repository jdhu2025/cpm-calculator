# CPM Calculator 项目资料

## 项目定位

这是一个围绕 `cpm calculator` 建设的免费在线工具项目。第一阶段目标是做出一个准确、易用、可被搜索到的 CPM 计算器；第二阶段再增加自然语言输入、预算模拟和广告投放报告等 AI 功能；第三阶段验证订阅、联盟和企业服务等变现方式。

## 当前状态

- 阶段：关键词研究与 MVP 规划
- 主关键词：`cpm calculator`
- 近似长尾词：`calculate the cpm`
- 数据来源：用户提供的关键词工具截图
- 数据日期：截图显示为最近 1 个月更新，具体平台和国家尚未确认
- 重要限制：Volume、KD、CPC 是第三方估算值；尚未做目标国家的实时 SERP 验证

## 初步机会判断

`cpm calculator` 的月均搜索量约为 27,100，KD 约为 27，CPC 约为 5.91 美元。它同时具备三项价值：有明确工具需求、有广告营销商业场景、有较高的商业点击价值。

最适合的切入方式是：

```text
免费 CPM 计算器
        ↓
搜索流量和工具使用
        ↓
广告预算/投放问题的进一步需求
        ↓
        联盟推荐、询盘、AI报告或订阅
```

## 最新判断：是否值得做

结论：值得做一个轻量的 SEO 工具站，但不建议一开始就把它做成纯订阅 SaaS。

原因：`cpm calculator` 有明确的工具搜索意图，搜索量和相关长尾词足够支持 MVP；但用户通常只需要计算一次 CPM，单独为计算器订阅付费的意愿较弱。更合理的产品路径是：

```text
免费 CPM Calculator
        ↓
广告预算和展示量计算
        ↓
多渠道比较、预算模拟和报告
        ↓
代理商、媒体主和团队版 SaaS
```

当前建议的优先级：

1. 先上线免费计算器，验证搜索流量和使用率。
2. 用联盟推荐测试第一笔收入。
3. 有稳定流量后再加入展示广告。
4. 用户出现重复使用需求后，测试付费报告。
5. 只有在真实用户提出需求后，再开发订阅、团队版或 API。

搜索量、KD、CPC 和收入估算均为第三方或假设数据，不能视为流量或收入承诺。

## 关键决策

1. 先做可验证的计算器，不先做复杂 SaaS。
2. 计算结果必须由确定性公式产生，AI只负责理解输入、解释结果和生成方案。
3. `calculate the cpm` 并入主页面，不单独复制一个几乎相同的页面。
4. 先验证用户是否愿意使用预算模拟和报告，再决定是否开发付费 AI 功能。

## 已实现的前端 MVP

实现目录：`cpm-calculator-app/`

技术栈：Next.js App Router + TypeScript，目标部署平台为 Vercel。

包含：

- CPM、预算、展示量三种计算模式；
- 首屏直接说明产品用途；
- 免费 AI 预算分析交互；
- AI 支持独立分析或读取计算器结果；
- 支持单选/多选平台和省钱、效果、性价比等分析路径；
- 预计 CPM、预算分配、三种情景对比；
- 平台适配矩阵和投放时间测试建议；
- 投放报告下载；
- 响应式桌面端和移动端布局。

本地运行：

```bash
cd cpm-calculator-app
npm install
npm run dev
```

然后访问 `http://localhost:3000/`。AI 分析通过 Next.js `/api/analyze-budget` Route Handler 调用；未配置 Key 时返回标注的本地估算。

部署到 Vercel：将 `cpm-calculator-app` 作为 Vercel 项目根目录，使用默认 Next.js 构建设置，并在 Vercel Environment Variables 中填写 `AI_API_URL`、`AI_API_KEY` 和 `AI_MODEL`。
