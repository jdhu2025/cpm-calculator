# Product Hunt media pack

## Upload order

1. `thumbnail.png` — upload in the Thumbnail field. It is 240×240 and under 2 MB.
2. `gallery-01-calculator.png` — first Gallery image and social preview.
3. `gallery-02-planning.png` — reverse-planning use case.
4. `gallery-03-metrics.png` — CPM/CPC/CPA context.
5. `demo.gif` — optional animated preview if Product Hunt accepts it in the Gallery field.

The images use the current CPM.calc visual system and show the actual product concepts: CPM calculation, reverse budget planning, and metric comparison. The dollar figures are illustrative examples, not performance claims.

## Short demo video

The repository includes `demo.gif` as an animated preview. If Product Hunt requires an MP4 instead, record the real production page rather than uploading a synthetic screen animation.

|---|---|---|
| 0–4s | Open the CPM calculator homepage | `Start with ad spend and impressions` |
